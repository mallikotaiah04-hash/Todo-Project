# 📝 Todo List Web Application

A simple and responsive Todo List web application built using HTML, CSS, and JavaScript. It allows users to manage their daily tasks efficiently.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Responsive and clean user interface
- Easy to use

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
Todo Project/
│── index.html
│── styles.css
│── script.js
│── img.png
│── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` or open it in your browser.
